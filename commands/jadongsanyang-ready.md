# 자동사냥 Ready

`/todos/` 디렉토리의 작업 목록을 분석하고 다음 작업을 추천합니다.

## 인자

`$ARGUMENTS`로 필터링할 수 있습니다:

- **경로 필터**: `자동사냥 준비 apps/feed` → `apps/feed` 관련 작업만 표시
- **우선순위 필터**: `자동사냥 준비 high` → High 우선순위만
- **키워드 검색**: `자동사냥 준비 refactor` → 키워드 검색

## 수행 단계

### 1단계: Todo 목록 수집

1. `/todos/` 디렉토리의 모든 `.md` 파일 읽기
   - **Glob 도구**로 `todos/**/*.md` 패턴 검색 (하위 폴더 포함)
   - **Read 도구**로 각 파일 내용 읽기
2. 각 파일에서 추출:
   - 제목 (`# ` 헤더)
   - 상태 (`## 상태` 섹션)
   - 대상 (`## 대상` 섹션) - 경로, 카테고리
   - 우선순위 (`## 우선순위`)
   - 예상 작업량 (`## 예상 작업량`) - 사람/Claude Code 두 가지 시간 포함

### 2단계: 필터링

`$ARGUMENTS`가 있으면:
- 경로로 필터링 (대상 경로 또는 파일 위치 기준)
- 우선순위로 필터링
- 키워드로 필터링

### 3단계: 상태별 분류

**미완료 (작업 가능)**
- `- [ ] 미시작` 또는 상태 섹션 없음

**진행 중**
- `- [ ] 진행 중`

**완료됨 (제외)**
- `- [x] 완료됨` 또는 `- [x] PR 생성됨`

### 4단계: 우선순위 정렬

미완료 항목을 다음 기준으로 정렬:
1. 우선순위: High > Medium > Low
2. 예상 작업량: 적은 것 우선
3. 의존성: 다른 작업의 선행 조건인 경우 우선

### 5단계: 목록 출력

```
📋 Todo 현황
📍 필터: [적용된 필터 또는 "전체"]

## 작업 가능 (N개)
| 파일명 | 제목 | 대상 | 우선순위 | 👤 사람 | 🤖 Claude |
|--------|------|------|----------|---------|-----------|
| xxx.md | 제목 | apps/feed | High | 2일 | 4시간 |

## 진행 중 (N개)
| 파일명 | 제목 | 대상 | 브랜치 |
|--------|------|------|--------|

## 완료됨 (N개)
(최근 5개만 표시)
```

### 6단계: 추천

가장 우선순위 높은 미완료 작업 추천:

```
🎯 추천: [작업 제목]
파일: [파일명]
대상: [경로]
우선순위: High
예상 작업량: 👤 사람 2일 / 🤖 Claude Code 4시간

추천 이유:
- [이유 1]
- [이유 2]
```

### 7단계: 다음 액션 제안

```
다음 중 선택하세요:
1. 이 작업 시작하기 → "자동사냥 시작 [파일명]"
2. 다른 작업 선택
3. 특정 앱만 보기 → "자동사냥 준비 apps/[앱이름]"
4. 새 아이디어 발굴 → "자동사냥 계획"
```

## 참고사항

- 완료된 작업도 기록으로 남아있어 이력 확인 가능
- 상태 섹션이 없는 레거시 todo는 "미시작"으로 간주
- 대상 섹션이 없는 레거시 todo는 "전체"로 간주
